# FK Sava — statički demo sajt

Sajt radi bez build procesa: otvorite `index.html` ili objavite ceo folder na GitHub Pages.

## Gde se menjaju podaci
- `assets/js/data.js` — godišta, demo igrači/statistike, utakmice i YouTube linkovi, galerija.
- `assets/images/` — fotografije i grb.
- `assets/css/style.css` — izgled.

Napomena: igrači i statistike su namerno demo podaci. Pre javne objave zameniti ih podacima koje klub/roditelji odobre.

## GitHub Pages
1. Napraviti repo i uploadovati sadržaj ovog foldera u root.
2. Settings → Pages → Deploy from branch.
3. Izabrati `main` / root.
